🐻 URSOS DE GUERRA

Uma equipe. Um propósito. Uma história.

Os Ursos de Guerra chegam à 10ª Gincana do CELRS 2026 representando força, coragem, união e determinação. Inspirados na força e resistência do urso, entramos nessa gincana preparados para enfrentar desafios, superar limites e representar nossa equipe com orgulho.

Não recuamos diante dos desafios. Caminhamos juntos para deixar nossa marca.

🐻 Por que o Urso?

O urso representa exatamente aquilo que queremos levar para esta gincana:

  • Força para lutar;
  • Coragem para enfrentar desafios;
  • União para caminhar juntos;
  • Resistência para nunca desistir;
  • Determinação para buscar nossos objetivos.

Os Ursos de Guerra entram na competição para lutar juntos, superar cada prova e representar nossa equipe com orgulho.

🖤 Nossa cor

PRETO

Para os Ursos de Guerra, o preto representa força, coragem, resistência, atitude e determinação. É uma cor marcante, intensa e que representa uma equipe preparada para enfrentar qualquer desafio.
